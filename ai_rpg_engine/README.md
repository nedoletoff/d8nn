# AI RPG Engine

Консольная текстовая RPG-песочница с ИИ-гейммастером.

**Главное правило:** вся механика (броски, HP, инвентарь, карта, квесты, время,
экономика, преступления) — **детерминированный Python**. Нейросеть — только
рассказчик: она разбирает намерение игрока в JSON и описывает результат, который
движок уже посчитал. Она не может менять числа, факты и прошлое.

---

## ✨ Возможности

- 🎲 Честные броски (`d20`, `NdM±k`), критический успех/провал, преимущество.
- 🔒 **Неизменяемый канон**: журнал только дописывается, защищён цепочкой sha256.
- 👁️ LLM видит только безопасную выжимку состояния — не весь лог и не seed.
- 🛰️ **Работает без интернета**: механика полностью играбельна, тексты шаблонные.
- 🗺️ Мир — **карта из клеток** (как шахматная доска) с туманом войны.
- 🌍 **6 прототипов мира** (см. ниже) + собственные правки.
- 🩹 **Правки игрока важнее движка**: «нет магии», «никто не умирает» и т.п.
- 🧵 Gruvbox-интерфейс на Textual (выделение мышью, копирование по Ctrl+C).
- 🔤 Эмодзи **по умолчанию выключены** (`EMOJI=false`) — вёрстка ровная; включаются `/emoji on`.

## 🚀 Быстрый старт (3 команды)

```bash
cd ai_rpg_engine
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Linux/Windows поднимется TUI. **Ключ не нужен** — без него игра работает в
оффлайн-режиме (текст шаблонный, вся механика на месте).

> ⚠️ На macOS игра не запускается (по задумке автора).

## 🧠 Подключить нейросеть (любую)

Подойдёт **любой OpenAI-совместимый** эндпоинт: OpenAI, DeepSeek, OpenRouter,
Groq, Together, локальный Ollama или LM Studio. Нужен только ключ, базовый URL и
id модели.

1. Возьми ключ у выбранного провайдера.
2. Создай `.env`:
   ```bash
   cp .env.example .env
   ```
3. Укажи провайдера и модель:
   ```dotenv
   LLM_API_KEY=sk-…
   LLM_BASE_URL=https://api.deepseek.com      # или …/v1 у OpenAI/Ollama и т.п.
   LLM_MODEL=deepseek-chat
   ```

Примеры:

| Провайдер | `LLM_BASE_URL` | `LLM_MODEL` |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| OpenRouter | `https://openrouter.ai/api/v1` | `deepseek/deepseek-chat` |
| Ollama (локально) | `http://localhost:11434/v1` | `llama3.1` (ключ любой) |

Запусти `python main.py` — в шапке будет `narrative online` вместо `offline`.

**Сменить на лету** (без правки файлов):
```
/model                      # список доступных моделей + текущая
/model deepseek-v4-pro      # переключить модель
/model endpoint https://api.openai.com/v1
/model key sk-…
```

**Проверка настройки** (без запуска TUI):
```bash
python main.py --check     # покажет: ключ, эндпоинт, модель, режим
python main.py --offline   # принудительно оффлайн (только движок)
```

## 🌍 Миры

При новой игре открывается **визард с вкладками**: Мир · Персонаж · Тон ·
Правила · Правки · Модель · Прошлые игры. Здесь можно:
- выбрать готовый мир или **«Свой мир…»** в списке — тогда появляется поле описания
  и кнопка «Создать мир с нейросетью»;
- задать имя, роль (или свою), **подписанные и редактируемые характеристики**,
  предысторию, мотивацию и «что с собой» **обычными словами** (нейросеть разберёт);
  либо **собрать персонажа с нейросетью** одной кнопкой;
- числа правил пишутся **одной строкой** свободным текстом — движок/нейросеть
  вытащат из неё значения;
- на вкладке «Модель» задать эндпоинт/ключ/модель и проверить связь.
Миры описывают эпоху, устройство магии и народы, но **не** фиксируют приключение —
завязку придумывает рассказчик. Инвентарь и квесты видно в боковой панели.

| id | Мир | О чём |
|---|---|---|
| `black_marsh` | 🌫️ Топь Забытых Огней | болотный фронтир |
| `witcher_dark` | 🐺 Пепельный Тракт | grimdark; знаки, чародейки, алхимия |
| `hobbit_classic` | 🕯️ Дорога к Дальней Горе | тёплое героическое фэнтези |
| `arcane_school` | 🧙 Академия Семи Шпилей | магия почти в современности |
| `neon_sprawl` | 🌆 Неоновый Спавл | киберпанк: импланты, корпорации, сеть |
| `ashen_wastes` | 🏜️ Пепельные Пустоши | суровый постапокалипсис (как Kenshi) |

Не хочешь отвечать на вопросы — введи **`/test`**: загрузится демо-мир, где уже
что-то произошло. Пересоздать мир — `/setup`.

### 🛠️ Создать свой мир (`/world`)

Опиши мир словами — дальше движок и нейросеть сделают черновик, который можно
довести руками:

```
/world new мрачное фэнтези о городе, построенном на костях кита
/world              # нейросеть структурирует, дополнит и исправит описание
/world check        # (по желанию) нейросеть проверит и поправит ошибки
/world refine добавь культ стеклодувов и запретную магию   # правки с нейросетью
/world accept       # финал — валидный мир появляется в списке
/world play <id>    # запустить · /world discard — удалить черновик · /world list
```

Черновик лежит в `data/worlds/_draft_<id>/` — файлы можно **править руками**
(финальный проход **без проверки нейросети**), затем `/world accept`.
Шаблоны и формат описаны в [`docs/world_format.md`](docs/world_format.md) и
`data/templates/`.

## 🩹 Правки важнее движка

Свои правила можно написать словами — на вкладке «Правки» или командой
`/mandate`. Нейросеть разбирает их в структуру: что менять в движке и **какие
свои права она теряет**.

```
/mandate магии не существует; никто не умирает; carry_base = 40; тон уютный
```
→ выключатся магия и смерть, грузоподъёмность станет 40, тон станет «уютным»,
а рассказчику будет прямо запрещено описывать магию и убивать.

Числовые правки идут **выше границ движка**. Отменить можно только неизменяемое
ядро: канон/прошлое и прямую запись состояния.

## 🎮 Основные команды

```
/help                     список команд
/main                     главное меню (мир, персонаж, правила, прошлые игры)
/rule <тема>              справка по механике (ничего не записывает)
/rules                    показать/менять правила мира
/mandate <текст>          свои правки (сильнее движка)
/world new|check|refine|accept|play|list|discard   создать свой мир
/roll 2d6+3 [причина]     ручной бросок
/map /inv /stats /quests /time /party
/travel <локация>  /talk <npc>  /say <текст>  /use <item>
/shop <npc>  /buy <item>  /sell <item>  /ask <вопрос о товаре>
/save [слот]  /load <слот>  /slots  /snapshot  /export  /log
/retcon list|undo <id>|edit <id> narration <текст>
/rules save <имя> · /rules load <имя> · /rules list
/model <имя>              сменить модель · /model — список · /model endpoint|key
/emoji on|off             включить/выключить эмодзи (ASCII-замены, ровная вёрстка)
/fudge on|off  /test  /setup  /exit
```

Запуск всегда открывает **главное меню** (`/main`, `/setup`, `/new`). Продолжить
сохранённую игру можно на вкладке «Прошлые игры», командой `/games` или
`/load <слот>`; из CLI — `python main.py --slot <слот>`.

Выход — **Ctrl+Q**. Текст истории можно **выделять мышью**, а **Ctrl+C**
копирует выделенное. История каждого хода пишется в `saves/<слот>/session.log`,
а команда **`/log`** сохраняет весь текст в `saves/<слот>/narrative.txt`.
(Для выделения нужен `textual>=3.0` — он уже в `requirements.txt`.)

**Автосохранение** включено по умолчанию (`AUTOSAVE=true`): игра записывается в
свой слот после каждого хода. Прошлые игры открываются на вкладке **«Прошлые
игры»** в визарде (`/setup`, `/new`) или командой **`/games`**; загрузить
конкретный слот — `/load <слот>`. При загрузке подтягиваются каталоги того мира,
к которому относится сохранение.

Просто напиши, что делает персонаж («иду к мосту», «бью тролля») — остальное
разберёт пайплайн.

## 🔐 Канон и сохранения

```
saves/<слот>/
├── meta.json            # время, HP, локация, активная ветка
├── state.json           # единственный авторитет по числам
├── canon_log.jsonl      # append-only, защищён хеш-цепочкой
├── canon_snapshot.json  # выжимка канона для нейросети
└── ui_prefs.json
```

`/retcon undo` не удаляет историю: создаёт новую ветку, а старый файл
сохраняется как `*.rejected.*`. Правка `narration` возможна только новым
событием `canon_amendment`.

## ✅ Тесты

```bash
pytest -q
```
Все тесты оффлайн (LLM замокан). Покрыто: кубы, канон/хеш-цепочка, состояние и
миграции, шесть движков, криминал (свидетели/улики/расследование), правила и
мандат, миры, LLM-слой, тема и виджеты, сборка приложения.
